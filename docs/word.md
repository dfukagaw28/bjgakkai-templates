# Word で書く

Microsoft Word で原稿を書く方法です。
見本のファイル `sample.docx` には、紀要の体裁（用紙・余白・2 段組・文字の大きさ・見出しの書式など）がすでに設定されています。
見本の文章を自分の文章に書き換えていけば、体裁の整った原稿になります。

**全体の流れ**

1. 見本をダウンロードする
2. 表題・著者名・要旨を書き換える
3. 本文を書く
4. 文献リストを書く
5. 提出前に確認する

## 1. 見本をダウンロードする

**[sample.docx をダウンロード](https://github.com/dfukagaw28/bjgakkai-templates/raw/main/docx/sample.docx)**

ダウンロードしたら、ファイル名を自分の原稿の名前（例：`yamada2026.docx`）に変えてから Word で開きます。
画面の上に「保護ビュー」の黄色い帯が出たら、**編集を有効にする** を押します。

> [!IMPORTANT]
> 用紙の大きさ・余白・段組み・文字の大きさ・フォントは変えないでください。
> これらは執筆要項に合わせて設定してあります。

## 2. 表題・著者名・要旨を書き換える

1 ページ目の上部（1 段組の部分）がタイトル部です。
上から順に、見本の文字を選んで自分の内容で上書きします。

| 見本の文字 | 内容 | 書き方 |
| --- | --- | --- |
| 研究論文 | 種別 | 研究論文・研究ノート・資料紹介・書評 のいずれか |
| 紀要「文化情報学」テンプレートの設計 | 表題 | |
| ―執筆要項に基づく…― | 副題 | 前後の「―」は残す。副題がなければ行ごと消す |
| 同志社 太郎・文化 花子 | 著者名 | 複数の著者は「・」で区切る |
| 本稿は、… | 要旨 | 和文・英文いずれでもよい |

> [!TIP]
> 文字を書き換えるときは、行全体を消して打ち直すのではなく、**見本の文字を選択して上書き** してください。
> 書式（文字の大きさや位置）がそのまま引き継がれます。

## 3. 本文を書く

タイトル部の下、2 段組の部分が本文です。
見本の本文を消して、自分の文章に置き換えていきます。

### スタイルについて

このテンプレートでは、見出し・本文・キャプションなどの書式を **スタイル** として登録してあります。
段落にカーソルを置くと、**ホーム** タブの **スタイル** の欄で、その段落のスタイルが分かります。

書式を自分で設定する（文字を太字にする、大きさを変える、など）のではなく、
段落ごとに適切なスタイルを選ぶのが基本です。
いちばん簡単なのは、**見本の中の同じ種類の段落をコピーして、文字だけ書き換える** 方法です。

主なスタイルは次のとおりです（Word の表示言語によって名前が日本語になるものがあります）。

| 使う場所 | スタイル名 |
| --- | --- |
| 節の見出し「1. はじめに」 | 見出し 1（Heading 1） |
| 項の見出し「2.1 節と項」 | 見出し 2（Heading 2） |
| 目の見出し「2.1.1 表記上の注意」 | 見出し 3（Heading 3） |
| 見出しの直後の段落 | First Paragraph |
| 本文の段落 | 本文（Body Text） |
| 数式の行 | Equation |
| 数式の直後に続く文（字下げしない） | Body Text Continued |
| 図 | Captioned Figure |
| 図のキャプション | Image Caption |
| 表のキャプション | Table Caption |
| 文献リスト | 文献目録（Bibliography） |

### 段落

段落の終わりで Enter キーを押すと、次の段落になります。
段落の先頭の 1 字下げはスタイルで自動的に付くので、全角スペースを入れる必要はありません。

### 見出し

見出しの番号は **自分で書きます**（自動では付きません）。
番号の後に半角スペースを 1 つ入れます。

| 種類 | 書き方の例 |
| --- | --- |
| 節 | `1. はじめに`（番号の後にピリオド） |
| 項 | `2.1 先行研究` |
| 目 | `2.1.1 国内の研究` |

節を途中に追加・削除したときは、それより後の番号を自分で付け直してください。
見出しの段落で Enter キーを押すと、次の段落は自動的に「First Paragraph」になります。

「謝辞」「文献」の見出しには番号を付けません。

### 注

注を付けたい位置にカーソルを置き、**参考資料** タブ → **脚注の挿入** を選びます。
注はページの下に脚注として出ます。
執筆要項では、注はなるべく使わないこととされています。

### 数式

数式は別の行に書き、行の右端に通し番号「(1)」「(2)」… を付けます。
見本の数式の行をコピーし、数式の部分をクリックして書き換えるのが簡単です。

一から作る場合は次のようにします。

1. 新しい段落を作り、スタイルを **Equation** にする
2. Tab キーを押してから、**挿入** タブ → **数式** で数式を入力する
3. 数式の後ろで Tab キーを押し、`(1)` のように番号を書く

数式の後に続く文は、スタイルを **Body Text Continued** にすると字下げされません。
番号は自分で付けるので、式を追加・削除したら付け直してください。
本文中では「式 (2)」のように番号で参照します。

### 図

1. 図を置きたい位置に空の段落を作り、スタイルを **Captioned Figure** にする
2. **挿入** タブ → **画像** で画像を入れる。幅は段の幅に収まるようにする
3. 図の **下** の段落に、スタイル **Image Caption** で「図 1　キャプション」と書く（番号の後は全角スペース）

### 表

1. 表の **上** の段落に、スタイル **Table Caption** で「表 1　キャプション」と書く
2. **挿入** タブ → **表** で表を作る

見本の表をコピーして中身を書き換えると、罫線などの体裁がそろいます。

図表の番号は自分で付けます。
キャプションは原則として日本語で書きます。
本文では「図 1 に示す」「表 2 のように」と番号で参照します。

<details>
<summary>2 段にまたがる大きな図表を入れたい場合</summary>

Word で 2 段にまたがる図表を置くには、その部分だけを 1 段組にします。

1. 図表の直前にカーソルを置き、**レイアウト** タブ → **区切り** → **セクション区切り（現在の位置から開始）** を選ぶ
2. 図表の直後でも同じようにセクション区切りを入れる
3. 図表の部分にカーソルを置き、**レイアウト** タブ → **段組み** → **1 段** を選ぶ

区切りを入れた位置で段組みが組み直されるので、図表はページの上端か下端に置くときれいに収まります。

</details>

## 4. 文献リストを書く

Word 版では、本文中の引用も文献リストも **自分で書きます**。
書き方は執筆要項 7. で決められています。
詳しくは [参考文献の書き方](references.md) を見てください。

### 本文中での引用

著者の姓の後に、発表年を西暦で書きます。
括弧は全角の（ ）を使います。

| 場面 | 書き方の例 |
| --- | --- |
| 文の一部にする | Gibson （1979） によれば…… / 佐伯・佐々木（1990）は…… |
| 文末などに添える | ……が提唱されている（佐伯・佐々木, 1990）。 |
| ページを示す | Haugeland （1987, p.123） |
| 同じ著者の複数の文献 | Simon （1973, 1981） |
| 同じ著者・同じ年の文献 | Cohen & Levesque （1990a, 1990b） |
| 複数の文献 | （安西 他, 1992; Joshi et al., 1981; Minsky, 1975, 1986a） |

- 欧文の著者が 2 人のときは「Cohen & Levesque」、3 人以上のときは「Joshi et al.」とします。
- 和文の著者が 2 人のときは「佐伯・佐々木」、3 人以上のときは「安西 他」とします。

### 文献リスト

本文（と謝辞）の後に、見出し「文献」を置き、その下に引用した文献をすべて並べます。
見本の文献リストの段落をコピーして書き換えると、スタイル（2 行目以降のぶら下げ）が引き継がれます。

- 番号は付けない
- 欧文・和文を区別せず、第 1 著者の姓の **アルファベット順** に並べる（和文の文献はローマ字読みで並べる）
- 同じ著者の文献は発表年の古い順に並べる。同じ著者・同じ年の文献は「1990a」「1990b」のように区別する

例：

> Cohen, P. R. & Levesque, H. J. (1985). Speech Acts and Rationality. *Proceedings of the 23rd Annual Meeting of the Association for Computational Linguistics*, 49–60.
>
> Gibson, J. J. (1979). *The Ecological Approach to Visual Perception*. Boston: Houghton Mifflin.
>
> Miller, G. A. (1956). The Magical Number Seven, Plus or Minus Two: Some Limits on Our Capacity for Processing Information. *Psychological Review*, **63**(1), 81–97.
>
> 佐伯 胖・佐々木 正人（編）（1990）．『アクティブ・マインド』．東京: 東京大学出版会．

### 謝辞と付録

- 謝辞は本文の後、文献の前に、番号なしの見出し「謝辞」を付けて書きます。
- 付録は文献の後に置き、見出しを「付録 A. 〇〇」「付録 B. 〇〇」とします。

## 5. 提出前に確認する

- [ ] 見本の文章・図・文献が残っていない
- [ ] 種別・表題・著者名・要旨が正しい
- [ ] 見出し・数式・図・表の番号が順に並んでいる（抜けや重複がない）
- [ ] 本文で「図 3」「式 (2)」のように参照している番号が正しい
- [ ] 本文で引用した文献がすべて文献リストにあり、リストの文献はすべて本文で引用している
- [ ] 文献リストがアルファベット順になっている
- [ ] ページ番号を付けていない（ページ番号は事務局が付けます）
- [ ] 分量が執筆要項の上限以内（研究論文は刷り上がり 20 ページ以内）

PDF が必要な場合は、**ファイル** → **エクスポート** → **PDF/XPS ドキュメントの作成** で保存できます。
提出するファイルの形式は、編集委員会の案内に従ってください。

## うまくいかないとき

| 症状 | 直し方 |
| --- | --- |
| 段落の書式が見本と違う | ホーム タブの スタイル で、その段落に正しいスタイルを選び直す |
| 書式がおかしくなって戻せない | 見本の同じ種類の段落をコピーし、文字だけ書き換える |
| 他のファイルから貼り付けたら書式が変わった | 貼り付けるときに右クリック → **テキストのみ保持** を選ぶ |
| 2 段組が 1 段になった、またはその逆 | セクション区切りを消したか、増やした。**ホーム** タブの **編集記号の表示/非表示**（¶）でセクション区切りを表示して確かめる |
| 図が段からはみ出す | 図を選び、四隅をドラッグして段の幅に収まるまで縮める |

ほかの質問は [よくある質問](faq.md) を見てください。
