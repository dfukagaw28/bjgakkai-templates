## 全般

### これは学会の公式テンプレートですか？

いいえ。紀要『文化情報学』の [執筆要項](https://www.bunkajoho.org/journal/jnl_yoko.html) に基づいて作った **非公式** のテンプレートです。
体裁は要項に沿うように作っていますが、投稿の際は必ず要項と編集委員会からの案内を確認してください。
要項とこのテンプレートの内容が違う場合は、要項が優先します。

### Word と LaTeX（Overleaf）のどちらを使えばよいですか？

迷ったら Word をおすすめします。
数式が多い場合や、文献の数が多くリストを自動で作りたい場合は、LaTeX（Overleaf）が便利です。
どちらで書いても、提出する原稿の体裁は同じになるように作ってあります。

| | Word | LaTeX（Overleaf） |
| --- | --- | --- |
| 準備 | Word があればすぐ使える | Overleaf のアカウントを作る（無料） |
| 見出し・図表・数式の番号 | 自分で付ける | 自動で付く |
| 文献リスト | 自分で書いて並べる | 引用した文献から自動で作られる |
| 慣れるまで | 短い | 少しかかる |

### GitHub のアカウントは必要ですか？

いいえ。テンプレートのダウンロードにアカウントは要りません。
不具合を [Issues](https://github.com/dfukagaw28/bjgakkai-templates/issues) で知らせるときだけ、GitHub のアカウントが必要です。

### テンプレートが更新されたら、書きかけの原稿はどうすればよいですか？

更新の内容は [リリースの一覧](https://github.com/dfukagaw28/bjgakkai-templates/releases) で確認できます。

- **Overleaf**：新しい zip をダウンロードし、中の `bunkajoho.cls`、`bunkajoho.bbx`、`bunkajoho.cbx` を、プロジェクトの同じ名前のファイルと差し替えます（アップロードすると上書きを確認されます）。`main.tex` と `sample.bib` は差し替えないでください。
- **Word**：更新の内容が自分の原稿に関係するかをリリースの説明で確認し、必要なところだけ手で直してください。

## 原稿の内容・体裁

### 原稿の分量はどのくらいですか？

要項 3. では次のように決められています。図表も分量に含まれます。

| 種別 | 分量 |
| --- | --- |
| 研究論文 | 刷り上がり 20 ページ（日本語でおよそ 30,000 字、英語でおよそ 18,000 単語）以内 |
| 研究ノート・資料紹介 | 研究論文の半分程度 |
| 書評 | 5 ページ以内 |

LaTeX 版は、刊行された論文と同じ字詰め（1 段 22 字 × 46 行 × 2 段）で組まれるので、ページ数が刷り上がりのページ数の目安になります。

### ページ番号は付けますか？

付けません。ページ番号は事務局が付けます。
テンプレートでもページ番号は出ないようにしてあります。

### 注（脚注）は使えますか？

使えますが、要項 5. で「注はなるべく用いない」とされています。
使う場合は、ページの下に脚注として付けます。

- Word：**参考資料** タブ → **脚注の挿入**
- LaTeX：`本文\footnote{注の内容。}`

### 図や写真は原稿にどう入れればよいですか？

要項 4. により、査読用の原稿では図表を本文中に埋め込んで提出します。
採択後の最終原稿では、図の部分を空白にし、十分な解像度の図のデータを別に提出します。

他の文献などから図表を転載する場合は、あらかじめ著作権者の了解を得て、出典を図表の箇所に書きます（要項 6.）。

### 英語で書けますか？

書けます。英語の論文の書き方は、要項に書かれていないことについて APA の *Publication Manual* に従うことになっています（要項 10.）。

- LaTeX：`\documentclass[paper,english]{bunkajoho}` のように `english` を加えると、種別（Research Paper など）、Acknowledgments・References・Appendix の見出し、Figure・Table のキャプションが英語になり、引用の括弧が半角になります。
- Word：見本の日本語の部分を英語に書き換えてください。

### どんな形式で提出すればよいですか？

提出するファイルの形式や方法は、編集委員会の案内に従ってください。
このテンプレートからは、Word 版なら docx と PDF、LaTeX 版なら PDF を作れます。

## Word

### 見出しの番号が自動で付きません

Word 版では、見出し・数式・図表の番号は **自分で書きます**。
節を追加・削除したときは、それより後の番号を付け直してください。
詳しくは [Word で書く](word.md#見出し) を見てください。

### 書式が崩れてしまいました

見本の中の同じ種類の段落をコピーし、文字だけを書き換えると元の書式に戻せます。
ほかのファイルから文章を貼り付けるときは、右クリック → **テキストのみ保持** で貼り付けてください。
ほかの対処法は [Word で書く](word.md#うまくいかないとき) にあります。

### 学会事務局の Word テンプレートとの違いは何ですか？

このテンプレートの Word 版は、学会事務局の Word テンプレートの用紙設定・2 段組・フォントをそのまま使い、
見出しや図表のキャプション、文献リストなどのスタイルを加えたものです。
体裁は事務局のテンプレートと同じになるように作っています。

### Mac の Word や LibreOffice でも使えますか？

Windows 版の Word を想定して作っています。
Mac 版の Word でも開けますが、メニューの名前や位置が [Word で書く](word.md) の説明と違うことがあります。
LibreOffice では表示が崩れる可能性があり、確認していません。

## Overleaf・LaTeX

### Overleaf は無料で使えますか？

はい。無料プランで十分に使えます。

### 日本語が表示されません／エラーが大量に出ます

コンパイラが LuaLaTeX になっていない可能性があります。
左上の **Menu** を開き、**Compiler** を **LuaLaTeX** にしてから **Recompile** してください。
ほかのエラーの対処法は [Overleaf で書く](overleaf.md#うまくいかないとき) にあります。

### 指導教員や共著者と一緒に編集できますか？

できます。Overleaf の右上の **Share** から招待してください。

### 自分のパソコンで LaTeX を使いたいのですが

TeX Live 2023 以降が必要です（LuaLaTeX、jlreq、biblatex、biber、原ノ味フォントを使います）。
[zip](https://github.com/dfukagaw28/bjgakkai-templates/releases/latest/download/bunkajoho-latex.zip) を展開したフォルダで、次のように実行すると PDF ができます。

```sh
latexmk main
```

## 文献

### 文献の書き方はどこに書いてありますか？

[参考文献の書き方](references.md) にまとめてあります。
要項に例のない文献（ウェブページなど）は、日本心理学会「[執筆・投稿の手びき（2022年版）](https://psych.or.jp/manual/)」に従います。

### 本文で引用していない文献も、文献リストに載せてよいですか？

いいえ。要項 7. では、文献リストは「本文中で参照した文献」をまとめたものとされています。
LaTeX では、本文で `\citet` や `\citep` で引用した文献だけが自動的にリストに載ります。

### 和文と英文の文献は分けて並べますか？

分けません。欧文と和文を区別せず、第 1 著者の姓名のアルファベット順に並べます。和文の文献はローマ字読みで並べます。
LaTeX では、和文の文献の bib データに `sortname`（ローマ字読み）を書いておくと、正しい位置に並びます。

### LaTeX で、引用がキーのまま太字で出てしまいます

bib ファイルにそのキーの文献がないか、キーの綴りが違っています。
本文の `\citet{...}` と bib ファイルの `@book{...,` のキーが一致しているか確かめてください。
